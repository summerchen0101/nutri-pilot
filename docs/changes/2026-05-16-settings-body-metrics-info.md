# 設定頁身體數據 BMI／BMR／TDEE 說明入口

**日期**：2026-05-16  
**影響規格**：docs/06-pages.md（設定頁呈現，未改欄位定義）  
**類型**：修改

## 原規格

06-pages 僅列出身體數據可編輯欄位與邏輯，未要求指標旁需有說明 UI。

## 實際做法

「身體數據」卡中 BMI、BMR、TDEE 列標題旁增加資訊圖示，點擊開啟 `BottomSheetShell`，內容說明各指標含義與計算假設（BMI 公式、Mifflin–St Jeor BMR、TDEE＝BMR×活動係數，以及設定頁 TDEE 顯示之備援說明）。非醫療診斷聲明寫於文案中。

## 原因

協助使用者理解數字來源與限制，避免誤解。

## 後續

可視需要將「設定內可查說明」補進 06-pages 一句話描述。
