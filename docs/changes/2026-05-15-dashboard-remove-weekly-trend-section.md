# 首頁移除「本週趨勢」區塊

**日期**：2026-05-15
**影響規格**：docs/06-pages.md（`/dashboard`）
**類型**：刪除

## 原規格

`docs/06-pages.md` 元件表未列出「本週趨勢」，但實作曾於首頁顯示 7 日體重線圖與熱量柱狀摘要。

## 實際做法

- 移除 `DashboardHome` 之本週趨勢 `SectionCard` 與相關 props。
- 首頁不再查詢近 7 日 `vital_logs` 供該區塊使用；刪除 `buildWeeklyTrend` 輔助函式。
- 週度體重／熱量趨勢仍以 `/analytics` 為主。

## 原因

產品收斂首頁資訊密度，趨勢分析集中於數據頁。

## 後續

若規格書需明文化「總覽不顯示週趨勢圖」，可於 `docs/06-pages.md` 補一行排除說明（目前表內本即未列該區塊）。
