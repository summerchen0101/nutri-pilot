# 商城：頁首捲離視窗時顯示購物車浮動按鈕

**日期**：2026-05-11
**影響規格**：docs/05-shop.md
**類型**：新增

## 原規格

規格書未描述商城列表／商品詳情等頁在捲動後如何再次開啟購物車（僅標註詳情頁 CTA、購物車流程等）。

## 實際做法

在 `/(main)/shop` 底下（`/shop/cart` 除外），當共用 `PageHeader` 錨點離開視窗時，右下角顯示圓形主色綠底、圖示為頁面色（白）之浮動按鈕；點擊行為與頁首購物車圖示相同（開啟側欄購物車面板）。按鈕 `z-index` 高於底部導覽、低於購物車面板。

## 原因

長列表／長內頁捲動後頂部購物車 icon 消失，需提供低摩擦的第二入口。

## 後續

可視需要將此行為補入 `docs/05-shop.md` 的 UX 說明；若希望購物車獨頁也顯示浮動入口，再調整 pathname 規則即可。
