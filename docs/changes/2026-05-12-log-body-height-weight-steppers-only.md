# 每日紀錄身體卡：身高／體重移除手動輸入欄

**日期**：2026-05-12  
**影響規格**：docs/06-pages.md  
**類型**：修改

## 原規格

身體卡可調整身高、體重並儲存；未明文限定輸入方式。

## 實際做法

身高、體重改為**僅能以加／減（步進 0.5）**調整並以唯讀數字區顯示；仍須按「更新身高／更新體重」送出。該日期尚無 `vital_logs` 體重時顯示「—」，可按「加」自 **60 kg**（並 clamp 於 15–400）起開始調整。

## 原因

簡化手機操作流程，避免與數字鍵盤輸入重疊。

## 後續

已於 `docs/06-pages.md` `/log` 身體與習慣區塊補述互動細節。
