# 儀表板體重入口改為前往紀錄頁身體分頁

**日期**：2026-05-10  
**影響規格**：docs/06-pages.md  
**類型**：修改

## 原規格

儀表板「體重」為彈窗輸入並呼叫 `logWeightAction`；快速操作「體重」同為彈窗。

## 實際做法

體重卡與快速操作「體重」改為導向 **`/log?date=<今日 ISO>&tab=body`**，於紀錄頁「身體」區調整並按「更新體重」儲存。移除儀表板 Client 端體重對話框與已不再使用的 **`logWeightAction`**（原為今日日期的薄包裝）。

## 原因

統一體重編輯體驗，與每日紀錄身體卡一致，並避免重複維護彈窗流程。

## 後續

規格書 `docs/06-pages.md` 儀表板區塊已同步更新。
