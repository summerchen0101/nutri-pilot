# 商城數字千分位與購物車預估總計主色

**日期**：2026-05-11  
**影響規格**：無對應單一章節（一般 UI／商城呈現約定）  
**類型**：修改

## 原規格

規格書未明訂商城金額與數字之位數格式或「預估總計」字色細節。

## 實際做法

- 新增共用格式化函式 `formatShopGroupedInteger`、`formatShopGroupedDecimal`（`Intl` locale `zh-TW`，千分位）。
- 商城列表、詳情頁營養標、同品牌卡、購物車行之金額與相關數字改經格式化輸出；購物車「預估總計」金額使用 `text-primary`（token 主綠），並維持 `tabular-nums`。

## 原因

易讀性與與全域主色系一致。

## 後續

可選將「商城數字千分位」補進 `docs/09-ui-design.md` 的快速參考。
