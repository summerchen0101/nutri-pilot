# 首頁熱量圓環：最高語意、鈉條與移除里程碑卡片

**日期**：2026-05-15
**影響規格**：docs/06-pages.md
**類型**：修改

## 原規格

`/dashboard` 熱量圓環呈現「今日攝取／目標」與三大營養素進度；首頁可顯示里程碑區塊。

## 實際做法

- `user_goals.daily_cal_target` 在該卡片上文字改為「最高」；進度環在接近最高（≥90% 且未超過）時為橘色、超過最高時為滿環紅色。
- 圓環卡右側進度區新增「鈉」橫條（`food_log_items.sodium_mg` 加總對固定參考上線 2400 mg，介面示意用）。
- 首頁不再渲染「里程碑」`SectionCard`；後端仍可同步並查詢 `user_milestones`（供連勝列邏輯使用）。

## 原因

產品用語統一為熱量「上限／最高」並強化視覺警示；鈉與紀錄頁一致可於總覽快速檢視；里程碑改不以首頁區塊呈現。

## 後續

已於 `docs/06-pages.md` 對齊熱卡描述；里程碑若將完全下線資料流可再評估移除查詢。
