# 設定頁改為摺疊分組 UX

**日期**：2026-05-15  
**影響規格**：docs/06-pages.md（`/settings` 呈現方式）  
**類型**：修改

## 原規格

06-pages 以「設定區塊表」列舉欄位與儲存觸發，未規定版面是否摺疊；實作先前為多張 `SectionCard` 直列、同時全部可見。

## 實際做法

`/settings`（`SettingsView`）在頁首與個人抬頭卡以下，將內容依主題分為四個可摺疊區塊：

1. 健康與目標（身體數據、飲控目標）
2. 飲食與脈絡（飲食偏好、個人化健康脈絡）
3. 商城與點數（會員購物點）
4. 帳號與 AI（帳號管理、AI 額度）

各區塊標題列顯示一行摘要；預設僅「健康與目標」展開。展開狀態以 `sessionStorage` 鍵 `nutri_settings_sections_v1` 於同次瀏覽階段記住（JSON，各區塊 boolean）。

## 原因

減少初次進入時的資訊密度與捲動長度，尤其「個人化健康／飲食脈絡」內容較長。

## 後續

可視使用回饋將 06-pages「元件區塊」小節補上一句「分組摺疊＋摘要列」描述，與程式一致。
