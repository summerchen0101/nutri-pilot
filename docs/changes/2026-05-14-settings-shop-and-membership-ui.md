# 設定頁：商城設定卡片與會員方案 UI

**日期**：2026-05-14  
**影響規格**：docs/06-pages.md  
**類型**：新增

## 原規格

`/settings` 區塊表列飲食偏好後即為帳號管理；帳號管理列「登出、查看訂閱方案」。頁面另曾含「購物配送資料」整塊表單常駐顯示（未於表格逐條列名）。

## 實際做法

- 新增 **商城設定**：摘要列預設顯示，`saveShippingProfile` 改以 **Bottom Sheet** 編輯；同卡含「飲食與推薦」列，捲動至飲食偏好錨點。
- 新增 **會員方案** 卡片：靜態展示免費／NT$199／NT$399、月費折抵與年繳占位說明、導向 `/shop`；**不**實作訂閱扣款（仍依 `05-shop.md` MVP）。

## 原因

與其他設定區塊一致採「摘要＋點選編輯」；商業與方案說明需在設定頁可見，但金流尚未接藍新定期定額。

## 後續

訂閱上線時：串 `subscriptions` 或新資料來源更新「目前方案」、補方案條款連結／Checkout。
