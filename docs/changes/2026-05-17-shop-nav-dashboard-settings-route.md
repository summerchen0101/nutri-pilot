# 商城底欄：詳情隱藏、總覽回儀表板、商城設定頁

**日期**：2026-05-17  
**影響規格**：docs/09-ui-design.md（主選單／商城導覽）  
**類型**：修改

## 原規格

- `/shop` 樹一律顯示商城專用底部五欄；首欄連至商城首頁、末欄連至全站設定。
- 商品詳情與其他 shop 子頁共用同一底欄。

## 實際做法

1. **商品詳情**：`MainAppShell` 在 `isShopProductDetailPathname` 時**不**渲染任一底部導覽；內容區 bottom padding 改小（`pb-8`）因無底欄。  
2. **商城底欄首欄**：改連 **`/dashboard`**，標籤「**總覽**」、`LayoutDashboard` 圖示（與全站主選單一致）。  
3. **商城底欄設定欄**：改連 **`/shop/settings`**，並於該路徑顯示 active。  
4. **固定路由**：`SHOP_FIXED_ROUTE_SEGMENTS` 新增 `settings`，避免誤判為動態 `productId`。  
5. **`/shop/settings`**：商城專用設定頁，含我的訂單、常用地址設定、購物金、優惠券與 `ShopSettingsSheet`；全站設定頁「商城與點數」折疊區**移除**重複捷徑列，僅保留點數卡與商城設定 sheet 入口。  
6. **文案**：捷徑列「常用地址」改為「**常用地址設定**」。

## 原因

詳情頁保留全寬閱讀與操作；商城內「回到主流程」改由總覽進儀表板；購物相關捷徑集中在商城設定頁以避免與 `/settings` 混淆。

## 後續

若需在儀表板顯示商城底欄，需另定跨樹導覽規則（目前僅 `/shop` 顯示 `ShopBottomNav`）。
