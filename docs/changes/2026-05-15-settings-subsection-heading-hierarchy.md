# 設定頁摺疊區內層標題層級調整

**日期**：2026-05-15  
**影響規格**：docs/06-pages.md（`/settings` 呈現方式）  
**類型**：修改

## 原規格

06-pages 以「設定區塊表」列舉欄位；摺疊分組見 `2026-05-15-settings-accordion.md`。實作上內層 `SectionCard` 仍使用與摺疊標題同級的 `SectionHeading`（15px + icon），部分標題語意與父層重疊（如「帳號與 AI」下再顯示「帳號管理」）。

## 實際做法

- `SectionHeading` 新增 `variant="nested"`（13px `text-heading-card`、較小 icon）；設定頁組內多卡時使用。
- 「商城與點數」「帳號與 AI」區塊內，移除與父層重複的單一／第一張卡標題（會員購物點、帳號管理）。
- 「AI 使用額度」改為「使用額度」；「個人化健康／飲食脈絡」UI 改為「口述健康脈絡」；飲食偏好 icon 改為 Utensils（避免與父層 Carrot 重複）。
- 摺疊展開面板增加水平內距（`px-3 sm:px-4`），與標題列區隔。

## 原因

摺疊 UX 上線後，大分類與小分類同字級並列，掃讀時像重複標題；需建立兩層視覺層級並刪除冗餘文案。

## 後續

可於 06-pages `/settings` 補充「分組摺疊＋組內卡片小標」描述；資料欄位與 API 行為不變。
