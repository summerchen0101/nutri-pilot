# 結帳側欄 MUJI 式資訊架構與版面

**日期**：2026-05-18

**影響規格**：[docs/05-shop.md](docs/05-shop.md)（流程仍為藍新 MPG 幕前；僅前端 IA／文案與側欄呈現）

**異動摘要**

- 結帳側欄改為淺灰底上分區白卡：運送方式摘要（含遮罩收件列、變更回購物車）、收件表單、付款方式說明（藍新導頁）、付款明細（總計在上、可摺疊商品清單）、購物須知＋連結。
- 側欄標題改為「結帳」；底欄改為左側總計、右側單一主 CTA「送出訂單」（`Button` default）；「返回購物車」改為捲動區內次要連結。
- **未**新增發票／載具區（與現行建立訂單 API 一致）；購物須知以短文＋連至 `/support` 為暫時入口，待專用法務頁可替換。
- 新增 [`src/lib/shop/mask-checkout-display.ts`](../../src/lib/shop/mask-checkout-display.ts) 僅供摘要列顯示遮罩。

**原因／後續**

- 對齊常見電商結帳層級與長文折疊，減少首屏噪音；金流與後端契約不變。若上線獨立條款／隱私頁，請更新 `CheckoutLegalHint` 的 `href` 與文案。
