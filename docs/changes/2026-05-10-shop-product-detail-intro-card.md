# 商品詳情：上方白卡與商品資訊簡介

**日期**：2026-05-10  
**影響規格**：docs/05-shop.md  
**類型**：修改

## 原規格

`/shop/[productId]` 表格列舉區塊包含「商品圖 + badge」「基本資訊」等，未逐一描述「商品資訊」標題區塊或上方區域須為獨立白底卡片；亦未規範簡介字數來源。

## 實際做法

- 主圖、分類／飲食標籤與「商品資訊」標題置於單一區塊，樣式與「規格與購買」一致：`rounded-xl`、`border-[0.5px] border-border`、`bg-card`，內文區 `p-4`。
- 「商品資訊」下方顯示 `products.description`；去除首尾空白後以 Unicode 字元數上限 80 顯示，超過則加省略號；無資料時顯示「尚無商品簡介」。

## 原因

與商城詳情 UI 一致（獨立白卡），並提供簡短文案以利使用者快速理解商品。

## 後續

可視需要將「商品資訊／簡介」條目補進 docs/05-shop.md 的 `/shop/[productId]` 表格。
