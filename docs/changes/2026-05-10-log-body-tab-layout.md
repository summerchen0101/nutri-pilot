# `/log`：主分頁 `body` 與熱量卡顯示範圍

**日期**：2026-05-10
**影響規格**：docs/06-pages.md
**類型**：修改

## 原規格

- `/log` 主分頁為 `food` / `activity`；身體與習慣表單與飲食摘要同路徑捲動呈現。
- 熱量加總與每日紀錄列表一併在紀錄頁可見（未區分分頁）。

## 實際做法

- 新增主分頁 URL 參數 **`tab=body`**（**身體與習慣**）：內含**雙卡**（**身體**：身高／體重；**水分與睡眠**：飲水格與睡眠）。
- **熱量加總**（今日已攝取 vs 目標）僅在 **`tab=food`** 顯示。
- 預設仍為 `tab=food`（或未帶 `tab`）。

## 原因

將身體／習慣與飲食紀錄分區，避免首屏過長，並與「飲食 / 運動」同一層導覽。

## 後續

- 若儀表板需提供捷徑至身體分頁，可另加連結 `/log?tab=body`（非本次必填）。
